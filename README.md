# TravelWithUs 

**TravelWithUs** is a simple and responsive travel website created using HTML and CSS. This website provides an elegant and informative layout for users who are interested in traveling to different destinations.

## Features

- Clean and modern design showcasing various travel destinations.
- Fully responsive design for mobile, tablet, and desktop devices.
- Includes key sections like:
  - **Introduction**: A welcoming message and brief description of what TravelWithUs offers.
  - **Featured Destinations**: Displaying popular travel destinations like New York, Italy, Thailand, Australia, New Zealand, and Arabia.
  - **Why Travel With Us**: Highlighting the reasons to choose this travel agency such as best deals, expert guides, and 24/7 support.
  - **Contact Us**: Details on how to get in touch with the company through email, phone, and social media links.

## Technologies Used

- **HTML5**: Used for structuring content.
- **CSS3**: Custom styles for layout, color scheme, typography, and responsiveness.
